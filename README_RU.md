## 📌 О проекте

**YMD** — консольная утилита для скачивания видео и извлечения аудиодорожек в формате MP3. Работает на базе [yt-dlp](https://github.com/yt-dlp/yt-dlp) и поддерживает множество медиаплатформ.

## ✨ Возможности

- Скачивание видео и извлечение аудио в MP3.
- Конвертация аудио с использованием наилучшего доступного качества исходника.
- Скачивание плейлистов.
- Настройка каталога загрузок.
- Просмотр текущего каталога загрузок.
- Просмотр пути к файлу конфигурации.
- Установка и удаление с помощью Python-скриптов.

## ⚙️ Требования

YMD поддерживает:

- Linux.
- Android через [Termux](https://termux.dev/).

Необходимое ПО:

- **Python** — для работы YMD и скриптов установки.
- **FFmpeg** — для извлечения и конвертации аудио в MP3.

Зависимости Python (`yt-dlp` и `platformdirs`) устанавливаются автоматически при установке YMD.

### Установка зависимостей

**Linux — Debian / Ubuntu:**

```bash
sudo apt install python3 ffmpeg
```

**Linux — Fedora:**

```bash
sudo dnf install python3 ffmpeg
```

**Android — Termux:**

```bash
pkg install python ffmpeg
```

## 🚀 Установка

1. Установите Python и FFmpeg.
2. Откройте терминал в каталоге проекта YMD, где находится `install.py`.
3. Запустите установщик:

```bash
python install.py
```

В некоторых дистрибутивах Linux используйте `python3 install.py`.

Установщик создаст отдельное виртуальное окружение, установит YMD и его зависимости, а также добавит команду `ymd` для запуска из терминала.

Проверьте установку:

```bash
ymd --help
```

Если `~/.local/bin` отсутствует в переменной `PATH`, добавьте этот каталог в настройки оболочки.

## 🕹️ Использование

### Скачать видео и извлечь аудио в MP3

```bash
ymd "VIDEO_URL"
```

### Скачать плейлист

```bash
ymd --playlist "PLAYLIST_URL"
```

Короткий вариант:

```bash
ymd -p "PLAYLIST_URL"
```

### Указать каталог загрузок

```bash
ymd --path "/path/to/downloads"
```

### Показать текущий каталог загрузок

```bash
ymd --get_path
```

### Показать путь к файлу конфигурации

```bash
ymd --config
```

## 🗑️ Удаление

Откройте терминал в каталоге проекта и выполните:

```bash
python uninstall.py
```

При необходимости используйте `python3 uninstall.py`.

Удаление убирает установленную команду и виртуальное окружение YMD. Файлы конфигурации также могут быть удалены установщиком удаления. Исходный код проекта и скачанные медиафайлы сохраняются.

## 🧩 Принцип работы

YMD использует [yt-dlp](https://github.com/yt-dlp/yt-dlp) для получения медиафайлов, а [FFmpeg](https://ffmpeg.org/) — для извлечения и конвертации аудио в MP3. Доступные форматы и качество зависят от исходного материала.

## ⚠️ Примечания

- Для работы требуется подключение к интернету.
- Поддержка платформ может меняться со временем.
- Скачивайте только тот контент, на загрузку которого у вас есть право и которую разрешают правила соответствующей платформы.
