## 📌 О проекте

**YMD** — консольная утилита для скачивания видео и извлечения звуковой дорожки в MP3-файлы. Работает на базе [yt-dlp](https://github.com/yt-dlp/yt-dlp) и поддерживает множество медиаплатформ.

## ✨ Возможности

- Скачивание видео и извлечение аудио в формате MP3.
- Конвертация аудио с использованием наилучшего доступного качества исходника.
- Скачивание плейлистов.
- Выбор пользовательской директории для загрузок.
- Просмотр текущей директории загрузок.
- Просмотр пути к файлу конфигурации.
- Установка и удаление с помощью Python-скриптов.

## ⚙️ Требования

YMD поддерживает:

- Linux
- Android через [Termux](https://termux.dev/)

Необходимое программное обеспечение:

- **Python** — запускает YMD и скрипты установки.
- **FFmpeg** — извлекает аудио и конвертирует его в MP3.
- **Git** — клонирует репозиторий YMD и его подмодули.

Зависимости Python (`yt-dlp` и `platformdirs`) устанавливаются автоматически при настройке.

### Установка зависимостей

**Linux — Debian / Ubuntu:**

```bash
sudo apt install git python3 ffmpeg
```

**Linux — Fedora:**

```bash
sudo dnf install git python3 ffmpeg
```

**Android — Termux:**

```bash
pkg update
pkg install git python ffmpeg
```

## 📥 Скачивание исходного кода

Клонируйте репозиторий вместе с подмодулем MicroLog:

```bash
git clone --recurse-submodules https://github.com/Vitner4/YMD.git
cd YMD
```

Если репозиторий уже был клонирован без подмодулей, инициализируйте их командой:

```bash
git submodule update --init --recursive
```

## 🚀 Установка

1. Установите Python и FFmpeg.
2. Откройте терминал в директории проекта YMD, где находится `install.py`.
3. Запустите установщик:

```bash
python install.py
```

В некоторых системах Linux используйте `python3 install.py`.

Установщик создаёт отдельное виртуальное окружение, устанавливает YMD и его зависимости, а также делает команду `ymd` доступной в терминале.

Проверьте установку:

```bash
ymd --help
```

Если `~/.local/bin` отсутствует в переменной окружения `PATH`, добавьте его в конфигурацию используемой оболочки.

## 📱 Установка на Android (Termux)

Следуйте этим шагам, чтобы установить YMD на Android.

### 1. Установите Termux

Установите Termux из [F-Droid](https://f-droid.org/packages/com.termux/) или из [официального репозитория на GitHub](https://github.com/termux/termux-app).

### 2. Обновите пакеты и установите зависимости

Откройте Termux и выполните:

```bash
pkg update && pkg upgrade
pkg install git python ffmpeg
```

### 3. Разрешите доступ к хранилищу Android

Выполните команду:

```bash
termux-setup-storage
```

Когда Android запросит разрешение, предоставьте Termux доступ к файлам.

### 4. Скачайте YMD

Клонируйте репозиторий вместе с подмодулями:

```bash
git clone --recurse-submodules https://github.com/Vitner4/YMD.git
cd YMD
```

### 5. Установите YMD

Запустите установщик из директории проекта:

```bash
python install.py
```

### 6. Проверьте установку

```bash
ymd --help
```

### 7. Выберите директорию для скачивания файлов

Чтобы сохранять загрузки в папку Downloads на Android, выполните:

```bash
ymd --path "$HOME/storage/downloads"
```

Найти скачанные файлы можно в папке **Downloads** с помощью файлового менеджера Android.

Чтобы в любой момент проверить текущую директорию загрузок, выполните:

```bash
ymd --get_path
```

**Примечание:** не удаляйте директорию проекта YMD, если в дальнейшем хотите запустить `uninstall.py`.

## 🕹️ Использование

### Скачать видео и извлечь аудио в MP3

```bash
ymd "VIDEO_URL"
```

### Скачать плейлист

```bash
ymd --playlist "PLAYLIST_URL"
```

Короткий вариант команды:

```bash
ymd -p "PLAYLIST_URL"
```

### Указать директорию для загрузок

```bash
ymd --path "/path/to/downloads"
```

### Показать текущую директорию загрузок

```bash
ymd --get_path
```

### Показать путь к файлу конфигурации

```bash
ymd --config
```

## 🗑️ Удаление

Откройте терминал в директории проекта и выполните:

```bash
python uninstall.py
```

Если этого требует ваша система, используйте `python3 uninstall.py`.

Деинсталлятор удаляет установленную команду и выделенное виртуальное окружение YMD. Конфигурационные данные также могут быть удалены деинсталлятором. Исходный код проекта и скачанные медиафайлы не удаляются.

## 🧩 Принцип работы

YMD использует [yt-dlp](https://github.com/yt-dlp/yt-dlp) для получения медиаданных и [FFmpeg](https://ffmpeg.org/) для извлечения и конвертации аудио в MP3. Доступные форматы и качество зависят от исходного источника.

## ⚠️ Примечания

- Для работы требуется подключение к интернету.
- Поддержка платформ может меняться со временем.
- Скачивайте только тот контент, на загрузку которого у вас есть право и которая разрешена условиями использования соответствующей платформы.
